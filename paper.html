Fast Approximate Parallax Shadows

Low-Sample Soft Self-Shadowing for Height-Mapped Surfaces

Abstract

Parallax occlusion mapping adds compelling depth to surfaces, but without self-shadowing the illusion falls flat. Existing soft POM shadow techniques require many samples to look good. We present Fast Approximate Parallax Shadows (FXPS), a modification to Tatarchuk's [2006] soft shadow formulation that targets the 2–4 sample regime. The technique uses square-root stepping, 1/i sample weighting, and normalization by iteration count N. The shadow probe operates in feature space: shadow intensity responds to the occluder's prominence within the height map's dynamic range, not to tangent-space geometry, making the probe self-calibrating across textures and parallax scales. We show that the 1/i weight produces log-uniform effective sensitivity—equal attention to each multiplicative decade of distance—for any power-law stepping function. The result is believable, distance-attenuated soft shadows at 2–4 texture fetches, at the same cost as hard POM shadows.

1. Introduction

Parallax occlusion mapping creates the illusion of surface depth using only a height map and a few texture fetches per fragment. But displacement without self-shadowing is unconvincing: the surface appears to have geometric depth, yet light passes through it unimpeded. Shadows ground the parallax effect, giving visual evidence that the height field has real volume.

Tatarchuk [2006] introduced soft self-shadowing for POM by replacing the binary intersection test of earlier relief mapping techniques [Policarpo et al. 2005] with a continuous depth-difference metric: rather than asking whether the height field intersects the light ray, the technique measures by how much each sample exceeds the ray, producing smooth shadow gradients. At high sample counts this works well. At the very low counts demanded by mobile GPUs, WebGL applications, legacy engines, and performance-constrained material layers (N = 2–4), however, linear sampling distributes budget uniformly along the ray with no mechanism for distance-dependent attenuation.

FXPS modifies Tatarchuk's formulation with three changes: a square-root sampling distribution, a 1/i sample weight, and normalization by N. Together these produce distance-attenuated soft shadows with contact hardening at 2–4 samples, for the same texture fetch budget as hard POM shadows.

A non-goal: FXPS does not target grazing light angles, where the macro surface itself becomes the occluder. At 2–4 samples, no stepping distribution can reliably detect own-surface occlusion at grazing incidence. For the dominant use case—terrain, building walls, and tiled surfaces under directional sunlight—this is not a practical concern. If the sun moves across the sky, grazing angles are fleeting; the technique spends its budget where the visual return is highest.

2. Feature-Prominence Probing

The conceptual anchor of FXPS is an observation about what POM shadow probes actually measure. The probe marches along the light vector in UV space and compares raw height-map values against the ray height. The depth difference ΔH = Hsample − Hray is dominated by the raw height difference between two points in the texture: at typical PARALLAX_SCALE values (0.03–0.05), the geometric ray correction is only a few percent of the height map's [0, 1] range. The correction provides directional awareness—ensuring only features in the light direction register—but it does not substantially affect the magnitude of the signal.

Shadow intensity is therefore proportional to feature prominence: how significant the occluding feature is within the height map's expressive range, not how large it is in tangent-space units. A brick edge that spans 20% of the height range produces the same shadow signal whether PARALLAX_SCALE is 0.02 or 0.08. This is appropriate for a perceptual heuristic. The probe auto-calibrates to each texture's content: a brick wall, a cobblestone surface, and a carved wooden panel all have different feature scales, but the shadow response adapts to what the height map actually contains.

3. Method

3.1 The 1/i Weight

FXPS weights each sample's contribution by 1/i, where i is the sample index (1, 2, …, N). With normalization by N (Section 3.3), the shadow value contributed by sample i is N · ΔH / i. This reaches 1.0 (full shadow) when ΔH = i/N, creating a distance-dependent prominence threshold:

1 (nearest)1/N = 0.2525% of height range

4 (farthest)N/N = 1.00Full height range

Nearby features need only moderate prominence to cast full shadow; distant features must span the full height range. This is the attenuation mechanism: distant features that cross the light ray but are not prominent within the height map produce only mild darkening, reflecting the intuition that at height-field scale, light still arrives from surrounding relief.

Log-uniform sensitivity. Consider the power-law family of stepping functions t(i) = (i/N)α. The sampling density is di/dt = (N/α) · t1/α − 1 and the weight is 1/i = 1/(N · t1/α). Their product—the effective sensitivity—is:

ρ ( t ) = 1αt

The exponent α cancels into a constant prefactor. The 1/i weight produces log-uniform sensitivity—equal attention to each multiplicative decade of distance—for any power-law stepping function. This is a useful invariance: the probe does not assume a characteristic occluder distance, and its relative attention to features at different scales does not depend on the choice of stepping exponent.

3.2 Square-Root Stepping

Since log-uniform sensitivity holds for any α, the stepping exponent is free to be chosen on practical grounds. We select α = 0.5 (square-root) for two reasons.

First, complementarity with normal mapping. In any pipeline that uses normal maps alongside height maps, the perturbed Lambertian term ⟨n′ · l⟩ already darkens fragments near occluders through surface-normal orientation. This provides effective near-field self-shadowing for free. The square-root distribution places all samples in the far field (t ≥ 0.50 at N = 4), detecting occluders that no amount of normal-map darkening can capture—a distant feature blocking light to a surface that locally faces the light.

Second, near-field noise avoidance. At small t the ray is barely above the surface, and minor variations produce spurious shadow contributions. Keeping samples at t ≥ 0.50 avoids this region. For N = 4:

Under square-root stepping, the 1/i weight corresponds to t−2 attenuation in ray-space (since i = N · t2, the weight 1/i is proportional to t−2). This is steep enough to produce strong contact hardening across the sampled range. The pairing of sqrt stepping and 1/i weighting is elegant: the same choice that places samples where they are most useful also produces the sharpest distance attenuation. We note that t−2 parallels inverse-square solid-angle falloff, though the connection is suggestive rather than formal.

3.3 Normalization by N

For an occluder at fixed ray position t*, the nearest sample index scales as i* ≈ N · t*1/α. The raw contribution is ΔH / i* ≈ ΔH / (N · t*1/α), which is inversely proportional to N. Multiplying by strength = N cancels this dependence exactly: the shadow response becomes independent of iteration count. N is a pure quality knob—changing it adjusts spatial resolution without affecting shadow intensity, and no secondary strength parameter is needed.

3.4 Implementation

float getParallaxShadow(sampler2D heightSampler, vec2 uv, vec3 lightDir)
{
    vec3 step = lightDir * PARALLAX_SCALE;
    float surfaceHeight = texture2D(heightSampler, uv).a;

    float shadow = 0.0;
    for (int i = 1; i <= PARALLAX_SHADOW_ITERATIONS; i++)
    {
        float t = sqrt(float(i) / float(PARALLAX_SHADOW_ITERATIONS));
        float rayHeight = surfaceHeight + step.z * t;
        float sampleHeight = texture2D(heightSampler, uv + step.xy * t).a;
        shadow = max(shadow, (sampleHeight - rayHeight) / float(i));
    }

    return clamp(1.0 - shadow * float(PARALLAX_SHADOW_ITERATIONS), 0.0, 1.0);
}

The function requires N + 1 texture fetches (identical to hard POM shadows) and one sqrt per iteration. No precomputed data, temporal accumulation, or stochastic sampling is required.

We evaluate FXPS against three baselines at identical texture fetch budgets: Tatarchuk's [2006] linear soft shadows, hard POM shadows (binary intersection), and N·L darkening only (no self-shadowing). We test across height maps with varying feature character (brick, cobblestone, organic terrain) and across sample counts N = 2, 3, 4, 8.

Feature-prominence invariance. To validate the feature-space property described in Section 2, we render the same height map at PARALLAX_SCALE values of 0.02, 0.04, and 0.08. Shadow patterns remain visually consistent, confirming that the probe responds to height-map topology rather than geometric depth.

Grazing angles. At light angles near the surface tangent, FXPS under-shadows because the t−2 attenuation discounts distant samples that would detect the macro surface acting as occluder. This matches the stated non-goal. The macro Lambertian term darkens these fragments regardless.

5. Limitations

FXPS does not detect own-surface occlusion at grazing light angles; this is an explicit non-goal at the target sample counts. The soft edge width is governed by the local height-field gradient and light angle, not by occluder distance—the technique does not produce distance-dependent penumbra widening. Height maps with compressed dynamic range produce weaker shadows, since the probe operates in the height map's [0, 1] range.
